### Hi, I'm Merve 👋

M.Sc. Data Science student at Dokuz Eylül University, working on both sides of applied AI: LLM systems (agents, RAG, evaluation) and classic machine learning (risk scoring and anomaly detection on imbalanced data). Recently I started working with image generation models, measuring how well they keep a design. My thesis studies how evaluation decisions such as prompting, token budget and answer extraction change the benchmark scores and rankings of open-source LLMs. I like building things end to end: the model, the API, and the tests that show it works.

### A few projects

| Project | What it is | Stack |
|---|---|---|
| [Interior Render Preservation](https://github.com/Mervecaliskann/interior-render-preservation) | Compares ControlNet methods for AI interior renders and measures how well they keep geometry and colors (edge recall, CIEDE2000 ΔE, CLIP). Adding the original photo cut color drift by 59% · [article](https://medium.com/@mervcaliskaan/does-the-ai-keep-your-design-measuring-geometry-and-color-in-stable-diffusion-interior-renders-43260ec239d3) | Stable Diffusion, ControlNet, CLIP |
| [Electricity Theft Detection](https://github.com/Mervecaliskann/electricity-theft-detection) | Risk scoring on meter data of 42K customers to prioritize field inspections. The top 20% riskiest customers cover 63% of theft cases. Includes SHAP explanations and a Power BI dashboard | XGBoost, SHAP, Power BI |
| [Explainable Credit Risk Scoring](https://github.com/Mervecaliskann/explainable-credit-risk) | Default-risk model with credit metrics (KS/Gini), SHAP explanations, and LLM-generated Turkish rationales | scikit-learn, XGBoost, SHAP |
| [Responsible AI Banking Agent](https://github.com/Mervecaliskann/responsible-ai-banking-agent) | A LangGraph banking assistant, hardened for regulated use: PII redaction (TCKN/IBAN), guardrails, audit logging, model card | LangGraph, Presidio, Groq |
| [Agent Benchmarking Lab](https://github.com/Mervecaliskann/agent-benchmark-pipeline) | Compares ReAct vs Plan-and-Execute agents with a statistical layer and BigQuery logging | BigQuery, SciPy, Streamlit |
| [AI Support Pipeline](https://github.com/Mervecaliskann/AI-Support-Pipeline) | Support tickets auto-categorized and prioritized by an LLM, served over a FastAPI API with a PostgreSQL backend and a Streamlit dashboard | FastAPI, PostgreSQL, Llama-3 |
| [Document Intelligence Extractor](https://github.com/Mervecaliskann/document-intelligence-extractor) | Extracts structured fields from invoice PDFs with an LLM, checksum validation and evaluation · [live demo](https://document--extractor.streamlit.app/) | Python, Groq, Streamlit |
